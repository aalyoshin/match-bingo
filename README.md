# Бінго на матч

**Грати: https://aalyoshin.github.io/match-bingo/**

Картка глядача на час трансляції. Сталася подія — тапнув по клітинці. Зібрав рядок, стовпець або діагональ — бінго.

Надішли посилання в чат. Кожен, хто його відкриє, отримає власну картку з тих самих подій, тож картки не збігаються.

## Свій список

1. Відкрий [gist.github.com](https://gist.github.com/).
2. Впиши події, по одній у рядку, щонайменше 24. Необовʼязково: рядок `# Назва` стане заголовком, а рядок `Центр: …` центральною клітинкою.
3. Збережи gist (secret теж підходить), у бінго вибери «Свій список» і встав посилання.

Приклад:

```
# Бінго: День народження Сашка
Центр: Задули свічки
Хтось запізнився
Тост на пʼять хвилин
Подарунок не того розміру
...
```

Посилання для компанії матиме вигляд `…/match-bingo/#g.<id gist>`, тобто близько 70 символів. Список завантажується з GitHub API: потрібен інтернет, а GitHub дозволяє 60 запитів на годину з однієї мережі. Після першого завантаження список кешується на пристрої на 30 хвилин.

## Як це працює

Код картки, набір і позначки зберігаються в адресі сторінки, наприклад `#euro-K7QM-35s`. Перезавантаження нічого не зітре, а посилання можна переслати собі на інший пристрій — картка відкриється та сама. Старі посилання на футбольні картки працюють як раніше.

## Як запустити

Завантажити `index.html` і відкрити у браузері. Один файл, без збірки та залежностей.
