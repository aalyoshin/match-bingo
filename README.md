# Бінго на матч

**Грати: https://aalyoshin.github.io/match-bingo/**

Картка вболівальника на час перегляду футболу. Сталася подія — тапнув по клітинці. Зібрав рядок, стовпець або діагональ — бінго.

## Як грати компанією

Усі відкривають посилання на своїх телефонах і натискають «Нова картка». Пул подій один, але набір у кожного свій, тож картки не збігаються.

## Деталі

Сітка 5×5, у пулі 44 події — від пенальті й червоної картки до коментатора, який згадав 2006-й. Центральна клітинка «Стартовий свисток» зарахована одразу.

Код картки й позначки зберігаються в адресі сторінки. Перезавантаження нічого не зітре, а посилання можна переслати собі на інший пристрій — картка відкриється та сама.

## Як запустити

Завантажити `index.html` і відкрити у браузері. Один файл, без збірки та залежностей.
